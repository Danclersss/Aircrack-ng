# Estado atual da monetização

Todo o sistema de venda de pacotes foi removido: checkout, Pix, pagamento manual/automático e confirmação de compras. O pacote Fundadores permanece reservado, sem preço ou botão de compra, para uma forma futura de obtenção. Pacotes com moedas do jogo e trocas de repetidas continuam disponíveis.

Anúncios são voluntários e dependem de uma conta aprovada e inventário configurado. Veja [ADS-SETUP.md](ADS-SETUP.md). Administração e recompensas por bugs estão descritas em [ADMIN-SETUP.md](ADMIN-SETUP.md).

## Repositório privado e hospedagem gratuita

O serviço web gratuito do Render pode continuar conectado a um repositório privado do GitHub, desde que a instalação do aplicativo Render tenha acesso ao repositório. Tornar o código privado não torna o site privado. O plano gratuito tem limites e suspensão por inatividade; o Supabase também possui limites próprios.

GitHub Pages em repositório privado exige um plano compatível; GitHub Free não mantém essa publicação privada. Para ficar no gratuito, mantenha o jogo servido pelo Render e confira a autorização do aplicativo após alterar a visibilidade do repositório. A visibilidade não foi alterada por este trabalho.
